## Highlights
- Daily code calculation interface using crane serial and selectable day, month and year.
- **Historical-date support:** use a date other than today.
- Three displayed code levels and copy controls.
- Client Portal with device/license status, trial access, updates and support navigation.
- Customers can contact **Support & Contact** for license purchase or renewal inquiries.
