# Install LIE_CRANE V2 on Android

> **Official app distribution:** [LIE_CRANE V2 GitHub Releases](https://github.com/liecranesupport-ai/LIE-CRANE-V2/releases)

**Current release candidate:** V2.2.4 (`com.engm.liecrane.client`).  
**Minimum Android:** Android 7.0 (API 24), as indicated by the submitted APK.  
**Distribution status:** An APK will become downloadable on GitHub **only after** a Release containing an APK asset is published.

## Installation
1. Visit the official **Releases** page above.
2. Select the latest available release and expand **Assets**.
3. Download the `.apk` asset.
4. Verify the SHA-256 against the value supplied on the same Release page.
5. Open the file and follow Android's prompts for permission to install from that browser or file manager, only if Android requires it.
6. After installation, open the application and complete the in-app customer/device access process.

**Do not** install APKs reuploaded by unknown third parties. The package is not distributed through Google Play.

## Trial and license purchase
The app manages its own device, trial and license eligibility checks. A trial may be available to eligible new customers; trial duration and availability are controlled by the app's server.

For license purchase or renewal, open the **Renew / Buy License** section of the **Client Portal**. To discuss pricing, payment options, activation or a device change, contact the team through **Support & Contact** in the app. No external website purchase is necessary.

## Using the date selection
1. Enter your crane serial number. Leading zeros are preserved.
2. Set the calculation day, month and year.
3. Choose a date different from today when needed — for example, a historical date corresponding to the date shown on the crane.
4. Tap **Calculate** and review the displayed result levels.

### Important
The user must be **authorized to access the relevant crane service functionality**. This app is independent, unaffiliated with Liebherr or other equipment manufacturers and does not replace approved service procedures, OEM documentation or lift-safety controls.

## Known installation questions

**Q: Do I have to buy a license from this GitHub page?**  
A: No. Access requests and purchase questions are handled within the app.

**Q: Can I run a calculation with a date different from today?**  
A: Yes; manual day/month/year selection is a core feature of the interface.

**Q: Can I use the app without internet?**  
A: Server access checks are part of the workflow. Do not assume offline access is supported.

**Q: Does the APK update a previous version automatically?**  
A: The APK must use a compatible signing identity and package name. Do not uninstall a working licensed installation just to test an unverified update.

**Q: Is the application officially supplied by Liebherr?**  
A: No. It is an independent third-party Android application.
