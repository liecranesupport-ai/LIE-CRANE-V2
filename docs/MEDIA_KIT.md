## Short description (for directory listings)
LIE_CRANE V2 is an independent Android daily code calculation tool for crane professionals, featuring crane-serial input, manually selectable calculation dates—including historical dates—multiple output levels, device-based license management, trial access and in-app customer support.

## Longer description
Need to calculate for a date other than today? LIE_CRANE V2 provides a practical Android workflow for authorized crane service personnel. Enter a crane serial, select any required day, month and year, and review the app's three separately displayed code levels.

The app also includes a Client Portal for verified device access, trial/license status, license purchase inquiries, renewals and support. Customers can contact support directly inside the app.

LIE_CRANE V2 is independently developed and is **not an official Liebherr or LICCON product**. Use is restricted to authorized work and does not replace manufacturer documentation or safety processes.
