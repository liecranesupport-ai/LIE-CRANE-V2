# LIE_CRANE V2.2.4 — Android Release

**LIE_CRANE V2** is an independently developed Android daily-code calculator for authorized crane service and maintenance professionals.

## ✨ Main capabilities
- **Selectable calculation date** — choose a past date or any different day, month and year rather than being limited to today.
- **Crane serial-number input**, including support for leading zeros.
- **Three displayed code levels** with copy controls.
- **Client Portal** for verified license/device access and trial eligibility.
- **Renew / Buy License** and **Support & Contact** — ask about purchasing or renewing licenses within the application.
- **App update notifications** where supported.

## 📥 Install
Download the **`V2.2.4.apk`** file from **Assets** at the bottom of this release. Install on a compatible Android device (Android 7.0+).

A connection to the app's backend service is used for device and access verification.

## 📩 Licensing / trial / technical support
Start the app and follow the in-app registration and access process. Eligible customers can use its built-in trial, while license purchase, renewal, activation and questions are handled via **Support & Contact** in the Client Portal.
