## How to write a useful Discussion

1. Search existing Discussions first.
2. Use an informative title (example: `Suggestion: faster way to switch between selected dates`).
3. Explain your context without including customer-specific information.
4. Be constructive, stay focused on authorized maintenance and software behavior, and respond respectfully to others.

Good topics: app navigation, date-picker usability, language support, documentation questions, accessibility and clearly described feature requests.

## How to report a useful bug

Open the [Bug report form](https://github.com/liecranesupport-ai/LIE-CRANE-V2/issues/new/choose). Provide:
- App version and Android version.
- Which screen or action was involved.
- Steps to reproduce, using fictional test input.
- Expected and actual results.
- Only public-safe and fully redacted screenshots.

**Do not post** real crane serial numbers, daily codes, controller outputs, customer details, device IDs, email addresses, order information, license tokens or customer account screenshots. Public repositories can be indexed by search engines, and deleting a comment may not remove copies.
